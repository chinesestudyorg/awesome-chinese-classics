## 原典与版本

- **[中国哲学书电子化计划（Chinese Text Project）](https://ctext.org/)**：检索和阅读古代哲学、历史及文学作品，部分文本附有对照译文。[项目介绍](https://ctext.org/introduction)说明了文本来源及正文数据库与维基材料的区别。提供中英文界面和简繁显示。引用前应核对版本、译者及 AI 译文标识；具体功能的访问和订阅条件请查看项目当前说明。

- **[CBETA 线上阅读](https://cbetaonline.dila.edu.tw/)**：按藏经、经名或关键词查找汉文佛典。藏经编号、原书行号和校勘信息有助于把搜索结果定位到可引用的段落。正文以中文为主，界面提供繁体中文、简体中文和英文。收录范围以各藏经目录为准，适合佛典阅读与查证。

- **[SAT 大正藏文本数据库](https://21dzk.l.u-tokyo.ac.jp/SAT/)**：检索《大正新脩大藏经》，并访问项目链接的相关图像库。与 CBETA 配合使用，可以比较同一引文的数字呈现或原书图像。包含汉文佛典，项目说明有日文和英文版本。使用前查看对应文本、图像库的收录范围和利用条件。

- **[中文维基文库](https://zh.wikisource.org/)**：由社区维护的中文作品录入文本，包含[《论语》](https://zh.wikisource.org/wiki/論語)等经典。适合按篇章浏览，以及查找关联版本。中文界面支持简繁转换。各作品的底本说明、校对进度和扫描图像情况不同，使用录入文本前应查看作品页面。

## 字词与字符工具

- **[汉典](https://zdic.net/)**：用中文查字、查词。[「學」字条目](https://zdic.net/hans/學)可见释义、旧字书材料、读音和字形信息。熟悉的字在古文中意思不通时，可用它比较不同义项。网页查询，解释以中文为主。需要分清历史字书的引文与现代释义，再放回原句判断。

- **[Pleco](https://www.pleco.com/)**：适用于 iOS 和 Android 的中文词典及阅读应用，提供手写查字和文档阅读工具，方便在阅读时查词。中文条目与英文解释取决于安装的词典。[基础下载与付费扩展](https://www.pleco.com/products/)的功能不同。先看所用词典的范围，不要默认每个释义都适用于古文。

- **[英文维基词典的中文条目](https://en.wiktionary.org/wiki/學)**：用英文解释中文字词的社区词典。链接中的「學」条目展示了读音、历史义项和例句，可与中文词典交叉查看。网页查询；不同条目的内容和来源详略不一。遇到字源或历史语言学判断，应继续查阅它引用的资料。

- **[Unicode Unihan 字符查询](https://www.unicode.org/charts/unihan.html)**：输入汉字或十六进制码位，查看编码资料、字典索引和读音属性。遇到难以输入或显示异常的生僻字时，适合先确认字符身份。说明文档以英文为主，字符数据涉及多种语言。它提供字符资料，不负责翻译句子；每个字可查到的属性也不同。

## 辅助阅读

- **[ChineseStudy](https://chinesestudy.org/)**：将部分中国经典的原文、拼音、现代汉语解释和译文放在一起，适合从短篇章开始读，再回到原典核对。提供英文、中文等语言入口，各作品与语言的内容情况不同。本项与维护者有关联：清单维护者同时维护 ChineseStudy。[编辑与使用范围说明](https://chinesestudy.org/en/about/)介绍了它面向日常阅读和入门学习的定位。

- **[Chinese Grammar Wiki（AllSet Learning）](https://resources.allsetlearning.com/chinese/grammar/Main_Page)**：用英文讲解现代汉语语法，附中文例句和拼音，按语法点与学习级别组织。适合需要帮助读懂经典的现代汉语说明的学习者。网页资料讲解的是现代汉语，分析文言文时不能直接套用。

## 一段原文可以这样读

1. 选一小段，记下作品名、篇章名和页面标注的版本。
2. 先读原文，标出不确定的字词与断句，再看译文。
3. 查字时比较几个可能的义项。现代词典排在第一位的解释，未必适合这句话。
4. 看译文或注释后回到原文，检查它如何处理主语、省略和关键词。
5. 用于正式引用或研究时，核对可靠版本并保留准确出处。不同数字文本的录入、标点与翻译可能有差异。
