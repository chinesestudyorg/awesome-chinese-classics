# Contributing

**PRs welcome.** Additions, clearer descriptions, source corrections, and access updates all help readers.

English and Chinese contributions are welcome. If you can only update one README, say so in the pull request; a maintainer can help keep the other version aligned.

## Suggest a resource

Open a resource suggestion issue or a pull request. Include:

1. The resource name and its official, canonical URL. Avoid tracking parameters and referral links.
2. The operator or maintaining community, and an official page supporting the description.
3. A concrete reading task it helps with and what it adds beyond existing entries.
4. The subject, available languages, known account or payment requirements, and a useful limitation.
5. The date you checked it and how you checked it. Distinguish a page you opened from a search result; report blocked access rather than guessing.
6. Any relationship you have with the resource: creator, employee, contributor, affiliate, or none.

Use your own words. Do not copy marketing descriptions, translations, or reference entries into the list. A link to an old text does not establish reuse rights for a modern translation, edition, image, or dataset.

## Selection and placement

We look for identifiable ownership or community maintenance, a clear use in reading Chinese classics, an official destination, and enough source information to describe the resource accurately. A paid resource is eligible when the cost or access model is stated; a specialist corpus is eligible when its scope is clear.

Modern Mandarin references belong under reading support and must be labeled as modern-language material. Broad directories, duplicate mirrors without a distinct use, unrelated services, unlicensed content mirrors, and descriptions written mainly to repeat search keywords are outside this list's scope.

Keep one entry per resource, place it with similar tasks, and use a short original description. Do not add promotional badges, star requests, invented popularity claims, promises of search rankings, or claims of complete coverage without specific supporting evidence. Resource creators may suggest their own work with disclosure; acceptance uses the same criteria as other suggestions.

The maintainer is ChineseStudy's founder. Changes to ChineseStudy's own entry must retain that disclosure and receive the same factual scrutiny as the other entries. Listing order is not a ranking.

## Correct or remove an entry

Give the affected URL, the observed problem, the date, and a supporting source when available. Useful reports include moved pages, new payment requirements, misleading scope, broken reading functions, and unclear provenance. Do not include passwords, account tokens, personal browsing data, or private correspondence.

A temporary network failure does not by itself prove that a project is abandoned. We may annotate uncertain access while checking an official announcement or a stable replacement URL. Readers and resource owners can both request corrections or removal.

## Before submitting

- Open the official link and the specific supporting page where possible.
- Read the rendered Markdown; check that the description is useful without promotional language.
- Keep names, destinations, scope, and maintainer disclosures consistent across both READMEs.
- Check local links to the contribution guide and language version.
- Keep private notes, local evidence, screenshots, credentials, and unrelated files out of the submission.

## 中文补充说明

可以用中文提交 Issue 或 PR。请提供官方链接、具体用途、语言、已知收费或登录条件、核查日期及资料来源；如果你参与了该资源的制作或运营，也请说明。只改一个语言版本时，在 PR 中注明即可。

欢迎指出版本来源、古义解释、访问条件或译文说明中的问题。不要复制第三方译注，也不要把暂时打不开的网页直接写成项目停止维护。
